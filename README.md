# GDChess

Pretty straightforward. GDChess is an open-source mod to play Chess directly in Geometry Dash!
Play against friends, random players or challenge the ultimate AI Stockfish!


# Compatibility
- android32: Soon. (First)
- android64: Soon. (First)
- Windows: Soon.
- iOS: Soon.
- macOS: Soon.

# Used:
- Geode SDK - Framework.
- C++ - Core.
- Cocos2d - UI and rendering.
- CMake - Builds

# Building from source

## Required:
- Git.
- CMake.
- Geode SDK.
- Compatible C++ compiler.
- Android NDK (for Android builds)

### Clone the Repository

```bash
git clone https://github.com/imAqwxiz/Chess.git
cd Chess
```

Build instructions will be provided as development progresses.

# Stockfish

GDChess (and Chess) mainly use Stockfish as the chess engine and intend to.

Stockfish can provide:
- AI opponent.
- Position evaluations.
- Best move suggestions.
- Game Reviews.

Stockfish is licenses under GPL-3.0. Its source code, network files and distribution requirements will be handled in accordance with their respective licenses.
